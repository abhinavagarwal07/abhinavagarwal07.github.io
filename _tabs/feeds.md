The Refute-or-Promote source lists 37 CVEs from my human-guided, AI-assisted research using Claude and Codex, with public records, attribution, and methodology sources.

- [Subscribe to the published CVE RSS feed](/feeds/refute-or-promote.rss)
- [Download the official CVE JSON record bundle](/feeds/refute-or-promote-cve-records.json)
- [Download the attribution and methodology source](/feeds/refute-or-promote.json)
- [Download the source-linked CVE list (CSV)](/feeds/refute-or-promote-cves.csv)
- [Read the Refute-or-Promote paper](https://arxiv.org/abs/2604.19049)

The CVE record bundle contains published CNA records in CVE JSON 5.2 format. Individual records are linked from the RSS entries, with their original metadata and CNA containers preserved. The attribution source carries finder and reporter credit alongside methodology evidence.

The RSS and JSON use stable URLs. Published updates appear at those same addresses as the inventory and its supporting sources change. RSS entries keep the same identifier for each CVE.
